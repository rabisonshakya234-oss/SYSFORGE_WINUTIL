
# Contributing to SysForge WinUtil

Thank you for your interest in contributing to SysForge WinUtil!

We welcome suggestions, bug reports, improvements, and contributions.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes and test them.
4. Commit your changes with a clear commit message.
5. Open a Pull Request describing your changes.

## Reporting Bugs

Please use the Bug Report template in the GitHub Issues section.

Include:
- A clear description of the problem.
- Steps to reproduce the issue.
- Windows and PowerShell versions.
- Screenshots or error messages when available.

## Suggesting Features

Use the Feature Request template to suggest new functionality or improvements.

## Code Guidelines

- Keep PowerShell code readable and organized.
- Use meaningful variable and function names.
- Avoid unnecessary changes to existing functionality.
- Test changes before submitting a Pull Request.

## Questions

For questions or project discussions, use the GitHub repository Issues section.

Thank you for helping improve SysForge WinUtil!
