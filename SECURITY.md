
# Security Policy

## Supported Versions

Security updates will be provided for actively maintained releases of SysForge WinUtil.

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability in SysForge WinUtil, please report it responsibly.

Please do not publish sensitive vulnerability details in a public GitHub issue.

Instead, use GitHub's private vulnerability reporting feature if it is enabled for this repository.

When reporting a vulnerability, include:

- A description of the security issue.
- Steps to reproduce the issue.
- Potential impact.
- Relevant screenshots or technical details.

## Response

The project maintainer will review submitted reports and determine appropriate fixes.

Thank you for helping keep SysForge WinUtil secure.
