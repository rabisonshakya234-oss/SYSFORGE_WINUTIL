# ⚡ SysForge WinUtil

### Simplifying Windows Management, Optimization & Customization.

**SysForge WinUtil** is a PowerShell-based Windows utility developed to make system management, optimization, and customization more accessible and convenient.

Managing Windows sometimes means navigating through multiple settings, executing individual commands, and performing repetitive administrative tasks. SysForge WinUtil aims to simplify these processes by bringing supported Windows utilities and management operations together in one place.

Built with simplicity, usability, and practical functionality in mind, SysForge WinUtil is an ongoing project created by **Rabison Shakya**.

---

## 📖 About SysForge WinUtil

SysForge WinUtil started with a simple idea: make Windows system management easier and more convenient.

The project uses PowerShell to provide access to supported Windows management operations through a centralized graphical interface.

Rather than requiring users to navigate through different system locations for every operation, SysForge WinUtil aims to provide a more organized way to access Windows utilities.

The goal is to build a practical Windows utility that combines useful functionality with a straightforward user experience.

## 🚀 Installation

Getting started with SysForge WinUtil is straightforward.

### Quick Installation

Open **Windows PowerShell** and execute the following command:

```powershell
irm https://raw.githubusercontent.com/rabisonshakya234-oss/SYSFORGE_WINUTIL/main/SysForge.ps1 | iex
```

This is the original installation command for SysForge WinUtil.

### Manual Installation

If you prefer to download the project manually:

1. Visit the SysForge WinUtil GitHub repository.
2. Click the **Code** button.
3. Select **Download ZIP**.
4. Extract the downloaded ZIP archive.
5. Open the extracted project folder.
6. Locate `SysForge.ps1`.
7. Review the script before running it.
8. Execute the script using PowerShell.

## 🔒 Security & Responsible Usage

SysForge WinUtil is designed to simplify Windows management while keeping users in control of their systems.

Before performing system-level operations, please consider the following:

* Review scripts and commands before executing them.
* Understand the purpose of each operation.
* Create a system restore point before significant system modifications.
* Back up important files and configurations.
* Run PowerShell with administrator privileges only when required.
* Avoid executing scripts from untrusted sources.

**Important:** Running a remote PowerShell script using `irm | iex` executes the downloaded code directly. For additional security, users should review the script contents before execution.
